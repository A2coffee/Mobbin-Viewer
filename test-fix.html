问题分析

问题：/raw/ 端点已被移除

Mobbin 更新后，原有的 /raw/ 图片端点返回 404 错误，导致扩展无法加载图片。

旧URL格式: https://bytescale.mobbin.com/.../app_screens/...
新URL格式: https://bytescale.mobbin.com/.../image/mobbin.com/prod/file.webp?enc=...
/raw/ 转换: https://bytescale.mobbin.com/.../raw/mobbin.com/prod/file.webp?enc=... ❌ 404

修复方案

解决：直接使用原始签名URL

修改 normalizeSignedFileToRawUrl 函数，不再尝试转换为 /raw/ URL，直接返回原始的 /image/ URL。

export function normalizeSignedFileToRawUrl(url: string): string {
  // Mobbin has removed the /raw/ endpoint, so we return the /image/ URL as-is
  // The signed URLs work correctly without conversion
  return url;
}

修复后的行为

签名URL将被原样保留
  • ✅ 识别新的签名URL格式（包含 enc= 参数）
  • ✅ 不再尝试转换为 /raw/ 端点
  • ✅ 直接使用原始 /image/ URL，可以正常加载
  • ✅ 去模糊功能继续正常工作

安装说明

  1. 打开 Chrome 浏览器，访问 chrome://extensions

  3. 点击"加载已解压的扩展程序"
  4. 选择项目的 dist 文件夹
  5. 访问 mobbin.com 测试功能
